# Beware — AI-Powered Buyer Return Risk & Dispute Assistant
> Evaluates Shopee buyer return claims and provides document-grounded dispute guidance for online sellers.

## Problem Statement
Shopee sellers face unfair inventory loss and shipping costs due to return abuse, fake claims, and auto-refunds. Beware provides instant, document-grounded dispute advice and evidence preparation 24/7.

## Evidence of the Problem
- Buyers select false return reasons so sellers pay return shipping fees upfront.
- Sellers suffer direct inventory loss from product swapping and unverified auto-approved refunds.

## Initial Related Work / Existing Approaches
- Shopee official support — contextual, but responses are slow and use static templates.
- Seller community forums — accessible, but advice is unverified and often misses appeal deadlines.
- General-purpose AI assistants — flexible, but not grounded in official Shopee Malaysia policies.

## Engineering Gap / Limitation
Existing approaches are slow, rely on unverified advice, or fail to ground dispute recommendations consistently in official marketplace seller documents.

## Project Objectives
- O1: Design a document-grounded AI seller dispute solution.
- O2: Develop the solution with retrieval and appropriate guardrails.
- O3: Evaluate answer quality, groundedness, latency, and safety.

## Target Users
Shopee Malaysia sellers, small e-commerce store owners, and customer support staff.

## Data Sources
- Shopee Terms of Service: Refunds & Return Policy (Shopee Help Centre)
- Shopee Seller Dispute & Evidence Guide (Shopee Seller Hub)
- Shopee Return Eligibility Guidelines (Shopee Help Centre)
